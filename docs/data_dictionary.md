# FlightInsight — словарь исходных данных (BTS)

**Источник:** [Bureau of Transportation Statistics](https://www.transtats.bts.gov/), **Reporting Carrier On-Time Performance (1987–present)**.  
**Период:** январь–март 2025 года.  
**Статус:** названия обязательных полей подтверждены скриптом `scripts/inspect_bts.py` во всех трёх CSV. Всего обнаружено 109 именованных столбцов и пустая техническая колонка в конце. Ниже перечислены **поля, существенные для FlightInsight**, а не все 109 полей источника.

| Поле BTS | Смысл и формат источника | Роль в системе |
| --- | --- | --- |
| `FlightDate` | Дата рейса `YYYY-MM-DD` | Дата, фильтрация, часть кандидатного ключа |
| `Reporting_Airline` | Код отчитывающейся авиакомпании | Связь с `airlines` |
| `DOT_ID_Reporting_Airline` | Идентификатор перевозчика BTS | Дополнительная проверка идентичности |
| `IATA_CODE_Reporting_Airline` | Код IATA перевозчика | Дополнительный код (может отличаться от отчётного) |
| `Flight_Number_Reporting_Airline` | Номер рейса | Кандидатный ключ, аналитика |
| `Origin`, `Dest` | Коды аэропортов отправления и назначения | Связи с `airports`, маршруты |
| `OriginAirportID`, `DestAirportID` | Идентификаторы аэропортов BTS | Сопоставление справочника аэропортов |
| `OriginCityName`, `DestCityName` | Город и штат/географическое описание | Отображаемые справочные сведения |
| `OriginState`, `DestState` | Двухбуквенные коды штатов | Справочник аэропортов |
| `CRSDepTime`, `CRSArrTime` | Местное время по расписанию, HHMM | Анализ времени суток; требует правильного преобразования |
| `DepTime`, `ArrTime` | Фактическое местное время HHMM, бывает пустым | Контроль и аналитика |
| `DepDelay`, `ArrDelay` | Отклонение в минутах, может быть отрицательным | Пунктуальность, средняя/медианная задержка |
| `DepDelayMinutes`, `ArrDelayMinutes` | Неотрицательная длительность опоздания в минутах | Сравнение с исходными signed-delay значениями |
| `Cancelled` | Статус отмены `0` / `1` (в CSV может выглядеть как `0.00`/`1.00`) | Учитывать отдельно |
| `CancellationCode` | Категория причины отмены; обычно неприменима к неотменённым рейсам | Анализ отмен |
| `Diverted` | Статус перенаправления `0` / `1` | Учитывать отдельно |
| `CarrierDelay` | Минуты задержки по причине перевозчика | Анализ причин задержки |
| `WeatherDelay` | Минуты задержки из-за погоды | Анализ причин задержки |
| `NASDelay` | Минуты задержки из-за ограничений национальной авиационной системы | Анализ причин задержки |
| `SecurityDelay` | Минуты задержки по причинам безопасности | Анализ причин задержки |
| `LateAircraftDelay` | Минуты задержки из-за позднего прибытия самолёта | Анализ причин задержки |
| `DayOfWeek` | Код дня недели в BTS | Проверить согласованность с `FlightDate` при ETL |
| `Distance` | Расстояние маршрута в милях | Контекст маршрута; не обязательно для MVP |

## Подтверждённые свойства трёх файлов

- Во всех трёх месяцах одинаковые заголовки; 109 именованных столбцов и завершающая пустая колонка.
- `FlightDate` корректно разбирается как дата во всех проверенных строках.
- Во всех обычных завершённых рейсах `ArrDelay` заполнен и разбирается как число.
- `Cancelled` и `Diverted` имеют распознаваемые булевы значения во всех строках.
- Пропуски значений существуют: особенно у фактического времени, задержек и пяти полей причин задержек. Их количества приведены в `docs/data_quality_report.md`.
- Отображаемого названия авиакомпании `airline_name` в перечне выбранных полей нет. Для него требуется авторитетный справочник перевозчиков; не генерировать названия по догадке.

## Соглашения о расчёте показателей

**Всего рейсов:** количество строк, соответствующих проверенным рейсам (после ETL — количество уникальных записей).  
**Обычный завершённый рейс:** `Cancelled = 0 AND Diverted = 0 AND ArrDelay IS NOT NULL`.  
**Задержанный по прибытии:** обычный завершённый рейс с `ArrDelay >= 15`.  
**Доля задержанных:** количество задержанных / количество обычных завершённых.  
**Пунктуальность (без задержки 15+ минут):** количество обычных завершённых с `ArrDelay < 15` / количество обычных завершённых.  
**Доля отмен:** количество отменённых / общее число рейсов.  
**Среднее отклонение от расписания:** `AVG(ArrDelay)` по обычным завершённым рейсам, включая отрицательные значения.  
**Среднее время опоздания задержанных:** `AVG(ArrDelay)` только для обычных завершённых рейсов с `ArrDelay >= 15`.  
**Медианная задержка:** медиана `ArrDelay` по явно указанной выборке.

При отсутствии знаменателя метрика должна возвращать `NULL` / «нет данных», а не деление на ноль. Все показатели фильтруются по явно указанному периоду, перевозчику и аэропорту.

## Уникальность и ограничения

Предварительный кандидатный ключ: `(FlightDate, Reporting_Airline, Flight_Number_Reporting_Airline, Origin, Dest, CRSDepTime)`. В пределах каждого из трёх месяцев проверка не обнаружила повторений, однако сам по себе результат **не доказывает**, что это корректное естественное ограничение уникальности для будущих периодов или корректировок BTS. Уточнение выполняется при проектировании PostgreSQL и ETL.

При разработке схемы проверить типы числовых полей, `NULL`, правильное преобразование HHMM, кодирование причин отмен и актуальность справочников. Не смешивать `ArrDelay` и `ArrDelayMinutes`: первый может быть отрицательным, второй — нет.
